# 布可找書 V1（臺南）

手機優先的單頁 HTML 原型，可直接使用瀏覽器開啟，也可放進 GitHub Pages。

## 現有功能
- 以低／中／高年級及指定臺南分館篩選。
- 27 本經布可星球官方書籍介紹頁核對的測試書籍，含 ISBN、作者、年級、布可挖掘連結。
- A：在架可借排序（**模擬體驗**；非即時館藏）。
- B：候補人數排序（**模擬體驗**；非即時候補）。
- C：電子書替代路徑（**模擬體驗**；目前沒有實際電子書對應查證）。
- 真實書單模式：前往臺南市立圖書館官方館藏查詢，並在本機記錄查詢結果；不會冒充即時資料。
- 收藏／想讀／已挖掘進度（儲存於瀏覽器本機）。
- 匯入布可星球官方 ZIP／ODS／XLSX／CSV／JSON 書單（前端使用 SheetJS 與 JSZip 的 CDN）。

## 立即測試
1. 在手機或電腦開啟 `index.html`。
2. 首頁預設為 **模擬排序模式**，切換年級、分館、A/B/C 分頁測試體驗。
3. 按「實際書單」可看到書籍與 ISBN，點「查官方館藏」後請在官方網站輸入 ISBN 查館藏。
4. 回到本頁，點「記下我查到的狀態」，在本機儲存自己查到的結果。
5. 要完整書單，至 https://read.tn.edu.tw/Guide.aspx 下載官方最新版 ZIP，再從頁面匯入。

## 放到 GitHub Pages
直接將 `index.html` 放在 repo 根目錄，啟用 Settings → Pages → Deploy from a branch (main / root)。

## 重要限制
- **未串接市圖即時館藏 API**；模擬借閱資料全部是虛構數字，使用時請勿據此前往借書。
- 官方書單匯入功能需網路以載入 CDN；若目前無網路，仍可用內建示範書單操作網站。
- 書單匯入器採欄位名稱自動識別；官方發布的新書單若欄位結構不同，可能需要更新解析規則。
- 圖書館連結導向官方搜尋首頁，不宣稱已自動帶入書目。
- 使用者的本機手動狀態不是可共享的館藏資料，會隨時間過期。
- 這是獨立非官方網站原型，不使用官方商標或宣稱官方授權。

## 後續 API 串接建議
由伺服器端（例如 Cloudflare Workers）建立與公共圖書館允許之 API 的介面，查詢 ISBN 對應的館藏狀態、可借分館、預約候補數與資料最後更新時間；前端收到確認過的資料後，再取代目前模擬模式。未取得 API 許可前不建議無限制抓取館藏頁面。
