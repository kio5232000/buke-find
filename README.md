# 布可找書 V2｜臺南親子閱讀工具

公開網站：<https://kio5232000.github.io/buke-find/>

幫家長找到可以到官方館藏系統查詢的布可書籍。這是**獨立、非官方工具**，不是臺南市政府教育局或臺南市立圖書館的官方服務。

## V2 已完成的資料串接

- **布可星球官方公開書單 → 本站 JSON**：GitHub Actions 使用 `scripts/sync_books.py` 下載教育局公開的書單 ZIP（網站挖掘指南的 `20250815` 版下載地址）；從 ODS 擷取 ISBN、書名、作者、分級、布可介紹連結和官方市圖查詢連結；每週一最多進行一次下載，只有超過最低資料量檢核才更新 `data/books.json`。可在 Actions > Sync official Buke books 手動重跑。
- **每本書的市圖 ISBN 直達查詢**：產生官方書單已採用的查詢網址格式 `https://lib.tnml.tn.edu.tw/webpac/search.cfm?m=ss&k0=ISBN&t0=k&c0=and`，直接到市圖 WebPAC 查該本書，免手動輸入 ISBN。
- **真實資料優先**：正式頁面預設真實書目模式，優先載入 `data/books.json`；當官方同步資料尚未建立或無法載入時，回退內建的 27 本已核對書籍。可繼續手動匯入更新檔（ODS/ZIP/CSV）。
- **本機紀錄**：從官方系統查到的館藏情況、排隊人數與電子書有無，可手動記錄在此裝置。超過 24 小時的館藏記錄會標示過期並從「在架」推薦中排除。

## 還不能宣稱已完成的功能

- **不能即時讀取市圖在架、借出、預約隊列人數**。臺南市立圖書館沒有確認開放第三方使用的即時館藏 API；不會顯示模擬狀態假裝有串接。
- **不能即時讀取電子書可借狀態**；提供官方資源入口，但是否有對應版本仍需人工查核。
- 官方書單的發佈版本與同步日期不同；本程序使用已公開的 20250815 完整書單來源，**不代表已包含 2026 年全部新上架書目**。若官方之後更新檔案網址，需要修改 `SOURCE`。

## 部署方式

專案主分支 `main` → GitHub Pages → root。`index.html` 為靜態網站，資料檔由 GitHub Actions 定期產生。

請檢查 Actions 的 `Sync official Buke books` 執行紀錄：**只有成功產生 `data/books.json` 才算「官方完整書單自動同步已啟用」**。未成功前網站仍可使用 27 本真實書目和市圖 ISBN 查詢捷徑。

## 技術與節制

- 官方書單是**一個公開下載檔案**，更新排程每週一次；不使用學童帳密、不下載個人閱讀紀錄、不嘗試繞過封鎖、不對 WebPAC 進行批次爬取。
- 程式只有 Python 3 標準庫依賴；遇到資料檔失效、欄位變更、資料筆數不合理時保留上次成功內容並讓工作流程失敗告警。
- 本機紀錄儲存在瀏覽器 `localStorage`，不會傳到這個 GitHub 儲存庫。

## 展覽用書（不外借）的處理
- 官方館藏狀態必須以「每一冊／每個條碼」判斷，不能把同一書名全部視為不可外借。
- 「展覽用書(不外借)」不可計入可外借冊數；即使可在館內閱讀也不列入「現在可借」或正常借閱候補。
- V2 可在手動紀錄中選擇「僅展覽用書」或「本館展示、其他館已確認可外借」，並在「館內閱讀」分頁查看這些本機紀錄。
- 手動在架與他館可借資訊超過 24 小時須重查；展示本標記仍保留，但不會把過期的他館可借紀錄當作有效。
- **注意：** 尚未自動取得各冊館藏狀態；未被標記的書仍可能包含不外借版本。不能將未確認的書視為可借。
