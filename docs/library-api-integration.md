# 布可找書 V3｜臺南市圖館藏介接規格（待館方確認）

**現況（2026-11-05）**
- 已完成：布可書單匯入、ISBN 官方查詢連結、逐冊借閱資格判斷模組、11 個單元測試。
- 尚未完成：取得臺南市圖正式館藏 API 權限或公開授權查詢介面、即時資料同步。請勿把爬蟲或過期公開頁面資料顯示為「即時可借」。
- 本站使用 GitHub Pages 靜態頁。正式 API 若需要金鑰或不允許前端跨域讀取，需另設具快取、限流的後端，不能把金鑰放在 HTML。

## 最小資料介面（示意，非真實館藏）

    {
      "isbn": "9789863203629",
      "checkedAt": "2026-11-05T08:00:00Z",
      "source": "authorized-api",
      "copies": [
        {
          "barcode": "館藏條碼",
          "homeLibrary": "典藏館",
          "currentLibrary": "目前所在館",
          "shelfLocation": "書架位置/館內閱覽限制",
          "status": "在架",
          "borrowable": true,
          "reservationCount": 0
        }
      ]
    }

borrowable 必須有可靠依據（正式 API 欄位或館方確認的流通政策）。單靠「在架」、預約按鈕、預約人數為 0 都不代表可外借。若無法確認，必須是 null，不推定 true。

## 核心判斷
1. 依 ISBN 查詢後，還需核對書目及每冊館藏條碼。
2. 「展覽用書(不外借)」、「限館內閱覽」等不流通書籍，不列入可外借冊數。
3. 展示本與一般可外借本並存時，正常可借複本仍可列入推薦。
4. 借出的流通複本可列入候補比較，但不能顯示為現在可借；候補人數定義須先由館方確認。
5. 過期查詢結果只能顯示需重新查詢。
6. 浮動館藏、閉館整修、運送中的冊數，須按館方規則判斷。
7. 不取得讀者帳密或個人借閱紀錄。

## 需要向館方確認的項目
- 是否提供可供第三方使用的 ISBN 書目搜尋、逐冊館藏與即時狀態 API？
- 是否能提供可否外借、典藏館、目前所在館、預約人數等欄位？
- 是否可供獨立親子閱讀網站使用；有無頻率、認證與資料標示限制？
- 館內閱覽、展示用書及浮動館藏的判斷規則？
- 若不提供 API，有無正式可申請的定期館藏資料匯出方式？
